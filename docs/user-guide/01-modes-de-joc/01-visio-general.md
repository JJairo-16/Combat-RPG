# Modes de joc

[← Tornar a l'índex](../INDEX.md)

---

## Què són els modes

Els modes de joc canvien les regles d'una partida abans que comenci el combat.

Un mode pot afectar:

- quines accions estan disponibles
- quantes perks pots aconseguir
- si hi ha perks divines
- si apareixen armes desbloquejables
- si el Caos pot intervenir
- si hi ha efectes especials de mode
- quines cinemàtiques es mostren

La base del combat continua sent la mateixa: crear personatges, escollir accions, gestionar recursos i adaptar-se al rival.

Els terrenys es trien a part del mode. Si els tens activats als ajustos, poden afegir una condició global després de crear els personatges.

---

## Modes disponibles

- **Principiant**: mode reduït per aprendre el combat.
- **Normal**: experiència completa.
- **El rostre fragmentat**: variant del mode normal sense Caos, amb fragments positius i negatius cada ronda.
- **Fam eterna**: variant del mode normal on la curació passiva desapareix i els atacs poden robar vida.

---

## Modes bloquejats

Alguns modes poden aparèixer ocults o amb pistes.

Quan un mode està bloquejat:

- no sempre veuràs el seu nom real
- pot mostrar una descripció incompleta
- les pistes indiquen quin tipus de progrés necessites

Els requisits poden dependre d'assoliments, descobriments o experiències concretes dins del combat.

---

## Com triar mode

Tria el mode segons el tipus de partida que vulguis:

- si vols aprendre o provar personatges, juga **Principiant**
- si vols la partida completa, juga **Normal**
- si vols adaptar-te a rondes imprevisibles, juga **El rostre fragmentat**
- si vols una partida més agressiva i amb menys recuperació segura, juga **Fam eterna**

---

## Consell de jugador

Canviar de mode no és només canviar la dificultat. Cada mode et força a valorar accions diferents. Una estratègia còmoda en Normal pot deixar de funcionar quan desapareix la curació passiva o quan cada ronda porta condicions temporals.
